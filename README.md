## Ringkasan
K-Means digunakan untuk mengelompokkan pelanggan berdasarkan usia, pendapatan, dan skor belanja. Hasil clustering dievaluasi menggunakan Elbow Method dan Silhouette Score.

## Temuan Utama
Scaling berpengaruh terhadap hasil pengelompokan K-Means karena perhitungan jarak dipengaruhi oleh skala fitur yang digunakan. Hal ini menunjukkan bahwa selain menentukan jumlah cluster yang sesuai, persiapan data juga perlu diperhatikan untuk memperoleh hasil pengelompokan yang lebih representatif.
